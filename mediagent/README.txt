# 🏥 MediAgent — Système Multi-Agent Biomédical

## Description
MediAgent est un système multi-agent intelligent dédié au domaine biomédical.
Il analyse les symptômes des patients et fournit des recommandations médicales
grâce à la collaboration de 3 agents spécialisés.

## Les 3 agents


🔍 Agent Symptômes : Analyse et identifie les symptômes 
🏥 Agent Médical : Consulte la base médicale 
💊 Agent Conseil : Génère des recommandations 

## Technologies utilisées

- Python 3.11
- Streamlit — Interface web
- LangChain — Framework multi-agent
- Groq API — Modèle LLaMA 3.3
- python-dotenv — Gestion des variables
